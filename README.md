TFLC School Management System (TFLC-SMS)
 
User Manual

Overview

The TFLC School Management System (TFLC-SMS) is a web-based application developed to streamline school operations at Tigbauan Fundamental Learning Center. It provides dedicated portals for Administrators, Teachers, and Parents to manage school information, attendance, communication, and student records efficiently.



 System Requirements

- Modern web browser (Google Chrome, Microsoft Edge, Firefox)
- Stable internet connection
- Valid user account



 Logging In

1. Open the TFLC-SMS website.
2. Enter your username.
3. Enter your password.
4. Click **Login**.



 Administrator Guide

 Dashboard

The Administrator dashboard provides an overview of:

- Total Students
- Total Teachers
- Attendance Summary
- Recent Activities


Student Management

 Add Student

1. Navigate to **Students**.
2. Click **Add Student**.
3. Fill in the required information.
4. Click **Save**.

 Edit Student

1. Select a student.
2. Click **Edit**.
3. Update the information.
4. Click **Update**.

 Delete Student

1. Select a student.
2. Click **Delete**.
3. Confirm the action.



 Teacher Management

The Administrator can:

- Add teachers
- Update teacher information
- Delete teacher accounts
- Reset teacher passwords

 Attendance Monitoring

Troubleshooting

| Issue | Solution |
|--------|----------|
| Unable to log in | Verify your username and password. |
| Forgot password | Contact the Administrator. |
| Attendance not loading | Refresh the page and check your internet connection. |
| Unable to access a module | Ensure you are logged in with the correct account. |



 Security Guidelines

- Keep your username and password confidential.
- Always log out after using the system.
- Use a secure internet connection.
- Report suspicious activity to the Administrator.

 User Roles

| Role | Responsibilities |
|------|------------------|
| Administrator | Manage students, teachers, inventory, reports, and system settings. |
| Teacher | Record attendance, manage assigned students, communicate with parents. |
| Parent | Monitor child attendance, receive announcements, and communicate with teachers. |
